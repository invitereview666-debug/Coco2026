阶段二 · 第3–6周

基础绘图技能

建立线条控制、图层思维、笔刷系统三大核心能力。这三样精通了，后面所有技巧都只是组合运用。

每周练习计划（量化）
  • W3
    线条控制训练
    每天画100条直线（不用QuickShape），目标：线条均匀无抖动。然后画200个圆圈，目标：起止点接合。用「技术笔」笔刷，不透明度100%。
    输出：一张充满线条练习的画布截图
    入门
  • W4
    图层系统实验
    创建10个图层：线稿层、底色层、阴影层、高光层、纹理层各一组。练习图层重命名、上色不出界（Clipping Mask）、隐藏/显示图层。
    输出：展示图层结构的截图
    入门
  • W5
    笔刷系统探索
    用15种不同笔刷各画一个圣诞球，感受手感差异。重点体验：技术笔（硬边）、水彩（渗透）、圆刷（厚涂）、干墨（纹理）。做成一张笔刷对比表。
    输出：15种笔刷对比展示图
    基础
  • W6
    第一件完整作品
    临摹一个圣诞球挂件（从Pinterest找参考图）。要求：轮廓层 + 底色层 + 高光层 + 阴影层，至少4个图层。颜色用传统红绿金配色。
    输出：可发布到社群的圣诞球插画
    基础

阶段三 · 月2–3

中阶技法精通

掌握这五大技法，你就拥有了专业数字插画师90%的工具箱。每个技法配一个实际练习项目。

五大中阶技法
正片叠底 Multiply
暗部阴影，让颜色变深。画阴影时放在颜色图层上方，永远不会过头。
阴影图层首选
滤色 Screen
亮部高光，让颜色变亮。圣诞球的金属反光、雪花的发光感专用。
高光/发光效果
叠加 Overlay
同时增加对比度，暗部更暗、亮部更亮。整体提升画面饱和度和生动感。
画面提色润色
颜色减淡 Color Dodge
强烈发光效果，火焰、星星、金属高亮专用。
极亮高光特效
颜色 Color
只改变颜色不改变明暗，用于整体换色调，快速测试不同配色方案。
配色实验利器
柔光 Soft Light
温和的对比增强，不会过曝，适合给整幅画加一层「质感层」。
纹理叠加
练习项目：画一个圣诞球，只用4个图层：底色层、正片叠底阴影层、滤色高光层、颜色减淡高光点。完成后你就理解了90%的光影原理。
①
剪切蒙版 Clipping Mask
在图层A上方新建图层B，右侧向下箭头 → 成为A的剪切蒙版。B上画的内容只在A的形状范围内显示。超级实用：画好线稿后，所有上色图层都剪切到线稿图层，颜色永远不会画出轮廓外。
↗ 最高频使用的遮罩技法
②
图层蒙版 Layer Mask
给图层添加遮罩，用黑色笔刷在遮罩上涂 = 隐藏对应区域，用白色涂 = 恢复显示。非破坏性——随时可以改，原图不受损。适合需要精细边缘的复杂裁剪。
↗ 非破坏性编辑核心工具
③
Alpha锁定 Alpha Lock
双指向右滑动图层缩略图启动。锁定后只能在已有像素范围内绘制——快速给形状整体换色、加纹理的利器。比剪切蒙版更快，适合简单上色修改。
↗ 快速上色换色首选
1
开启对称：修改(S形) → 画布 → 绘图参考 → 对称
四种模式：垂直（左右镜像）/ 水平（上下镜像）/ 四象限 / 放射状（雪花/曼陀罗）。
2
放射状对称 → 雪花图案
设为6点放射，画左边，右边自动镜像出现，一分钟出一个完美雪花图案。毛毡挂件图纸的核心制作方式。
3
垂直对称 → 动物/人偶正面图
画雪人/麋鹿等对称立体造型时，只需画左半边，右边自动生成，大幅减少出错率。
1
设置正方形画布（建议2000×2000px）
无缝图案必须用正方形。DPI设300（打印级别），如果只用于数字用途可以72dpi。
2
开启「画布参考」，选择对称/重复模式
或者用传统方法：画好元素 → 变换工具移到边缘一半 → 复制 → 移到对边，确保接缝处完美衔接。
3
分层管理：元素层、背景层各独立
方便后期快速更换背景色，测试不同配色方案而不重新画。
4
导出PNG → Spoonflower / Adobe Illustrator转矢量
Procreate是像素图，如需授权给布料印刷厂，需要转矢量。用Adobe Capture App可直接从Procreate导矢量路径。
商业应用：一套圣诞主题无缝图案（雪花、麋鹿、铃铛等5–8个元素），可以用在：毛毡产品的包装纸、Etsy数字下载产品、圣诞贺卡印刷。是Procreate最直接的变现路径之一。

阶段四 · 月3–6

走向自主设计

从「临摹复制」到「原创输出」的最关键转变。这不只是技术问题，更是设计思维的建立过程。

原创设计工作流（6步法）
1
灵感收集 — Pinterest Board
每周建一个主题灵感板：「北欧圣诞」「日本民艺」「70年代配色」「苔藓植物」——任何让你有感觉的视觉主题。不是抄，是训练你的视觉语言库。在Procreate里新建画布，截图参考图贴进来，旁边写下「我喜欢这里的XXX」。
量化目标：每月至少5个主题灵感板，每板20–30张图
2
关键词提炼 — 把感觉变成词
从灵感板中提炼3个形容词，例如「温暖 · 手感 · 北欧」。这3个词是你这件作品的设计关键词，所有决策（配色/笔触/构图）都回来问：「这个选择符合这3个词吗？」
这是把「我觉得好看」变成「我知道为什么好看」的转化点
3
缩略草图 — 快速概念发散
新建一张512×512px的小画布，5分钟内画出5个不同的构图草图（缩略图级别，不要细化）。选其中一个继续。速度是关键——小画布强迫你只关注大形状和构图，不在细节上纠结。
职业插画师的黄金法则：先数量，再质量
4
线稿 — 结构与比例
新建正式画布（3000×3000px），在最底层画线稿。线稿图层透明度降到30–40%，在上方新建「上色」图层组。技巧：用对称工具画对称图形，用QuickShape画完美几何形状（画完后按住）。
线稿不需要完美，但比例要对
5
配色实验 — 在数字端就测试
底色填好后，新建「配色测试」图层，用「颜色」混合模式整体改变色调，快速测试3–5个配色方案，截图对比选最好的。比买羊毛试配色便宜100倍，这是Procreate最大价值之一。
先数字定色，再买实体材料——省钱法则
6
转化为实体图纸 — Procreate → 手工
导出PNG → 用AirPrint打印到A4纸，或直接在iPad屏幕上描摹（用手势锁屏，防止误触）。毛毡作品：打印轮廓图，对照着戳针。刺绣：打印稿放在布料下用透光桌描图。钩织：在Procreate标注针数圈数，导出PDF图纸。
数字 ↔ 实体的桥梁，Procreate是你的「数字打样台」
走向原创的核心转变：临摹教你「怎么做」，自主设计要你决定「做什么」。最快的训练方法是「主题限制法」——给自己一个限制（只用3种颜色 / 只画圆形 / 只用一种笔刷），在约束内创作。限制越多，创意往往越丰富。
配色设计系统

Procreate 配色完全指南

配色是手工艺产品销量最直接的影响因素。在Procreate里先做配色实验，再买材料——这是最聪明的工作流。

Procreate 色彩工具使用
🎨
色盘 (Color Disc) — 色相 + 饱和度 + 明度三维控制
外圈选色相，内圈调饱和度和明度。点右上角颜色图标进入。技巧：先在外圈选大方向色相，再在内圈的左下角区域选「低饱和度暗色」（阴影用），右上角选「高饱和度亮色」（亮部用）。
📦
调色板 Palettes — 保存你的专属色系
颜色面板下方 → 调色板 → 新建。建议为每个产品系列建一个调色板：「圣诞经典」「北欧系」「奢华金」各存5–7个颜色。可以从照片提取颜色：点「+」→ 从照片，从竞品图或自然场景里提取配色。
🔢
HEX值输入 — 精确颜色控制
颜色面板右上角点「HEX」标签，可以直接输入HEX色码。用Coolors.co生成配色方案 → 复制HEX码 → 粘贴到Procreate，精确实现设计配色。

色彩理论速查（设计师必知）
互补色
色轮对面的颜色（红 vs 绿）。最强烈对比，圣诞经典配色的底层逻辑。
类似色
色轮相邻的颜色（红-橙-黄）。柔和和谐，北欧风配色常用。
60-30-10法则
主色60% · 辅色30% · 点缀10%。超过3种主色必乱。
色温
暖色（红/橙/黄）= 前进感/热闹。冷色（蓝/绿/紫）= 退后感/平静。
饱和度对比
高饱和色 + 低饱和色对比。让主角「跳」出来的关键。
明度对比
明暗差异决定立体感。没有明度对比 = 平面，有明度对比 = 立体。
Procreate 配色实验法：画好一件作品底稿后，复制画布5次，每次用「选色」混合模式图层覆盖，快速测试5套配色方案，30分钟内完成所有方案对比，选最好的再精修。这个方法可以帮你避免「买了材料才发现配色不好看」的损失。

产品图制作工作流（亚马逊/Etsy适用）
📸
步骤1：拍摄原始产品照
自然光侧光，米色/白色背景，保持1000px以上清晰度。不需要专业相机，iPhone + 自然光就够。
✂️
步骤2：导入Procreate → 去背景
使用「选取 → 自动」点击背景区域，删除背景。或者用「快速选择」精细抠图。导出PNG透明背景。
🖼
步骤3：合成场景图
新建画布，底层放背景（松枝纹理/木板纹理/牛皮纸），中层放产品，上层加文字/品牌标志。一个产品可以快速出3–5张不同风格场景图。
📊
步骤4：信息图 Infographic
用Procreate制作「材质说明」「尺寸标注」「套组内容物」等信息图，直接提升转化率。文字用简洁无衬线字体，配色与产品一致。
